# 서비스 Agent 업무 지침

이 폴더는 **향후 서비스 안에서 동작할 LLM Agent**에게 줄 업무 절차다.
저장소를 개발하는 Claude Code의 스킬(`.claude/skills/`)과 다르다.

## 연결 상태

| 지침 | 업무 | 서비스 연결 |
| --- | --- | --- |
| [staff-assignment-lookup](staff-assignment-lookup/SKILL.md) | 인력의 현재·과거 투입 조회 | 미연결 (도구는 구현됨) |
| [contract-expiry](contract-expiry/SKILL.md) | 구매계약 기간·종료 예정·만료 알림 조회 | 미연결 (도구 일부 구현) |

- **미연결**: LLM API가 아직 연결되지 않아 이 문서를 읽는 Agent가 없다. 문서가 있다고 서비스에서 동작하는 것이 아니다.
- 도구는 `pmo/tools.py`에 정의되어 있고, 구현 여부는 각 지침의 "연결 도구" 표를 따른다.
- 도구 이름·입력을 바꾸면 이 지침과 `evals/questions.json`을 함께 고친다.

## 공통 원칙

- 조회·계산·저장은 도구로만 한다. SQL을 만들거나 결과를 추측하지 않는다.
- 이름만으로 인력을 확정하지 않는다. `find_people` 결과가 여러 명이면 업체·관리번호로 대상을 물어본다.
- 등록·변경은 미리보기 후 사용자 확인을 받는다(저장 도구는 구현 예정이므로 현재는 화면 사용을 안내한다).
- 도구가 `ok: false`를 돌려주면 오류 내용을 그대로 설명하고, 성공한 것처럼 답하지 않는다.
- 날짜는 Asia/Seoul 기준이다. 답변에 기준일을 밝힌다.
