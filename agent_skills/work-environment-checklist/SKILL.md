# 근무 환경 준비 현황 조회

## 사용 시점

- "A 차장 근무 환경 준비 어디까지 됐어?"
- "다음 주 투입자 중 준비 안 된 사람 있어?"
- "ID카드 신청 안 된 인력 알려줘."

## 필수 입력

| 요청 | 필수 입력 | 없을 때 |
| --- | --- | --- |
| 개인 준비 현황 | 인력(관리번호로 확정) | `find_people`로 찾고 동명이인은 선택 요청 |
| 준비가 남은 투입 목록 | 없음 | - |

## 실행 절차

1. 개인: `find_people` → 1명 확정 → `checklist_status(person_id)`. 투입이 여러 건이면 투입 과제·기간별로 나눠 답한다.
2. 전체: `checklist_status()` → 준비가 남은 투입(종료되지 않은 투입, 시작일이 가까운 순).
3. 특정 항목(예: ID카드)만 물으면 결과에서 그 항목만 골라 답한다.

## 연결 도구

| 도구 | 상태 | 용도 |
| --- | --- | --- |
| `find_people` | 구현 | 인력 확정 |
| `checklist_status` | 구현 | 투입별 4개 항목 상태·사유·초안 작성 시각·실제 신청 완료 시각 |
| `query_database` | 구현 | 그 밖의 조건 조회·건수 집계 (SELECT만) |
| `prepare_checklist_update` | 구현 | 항목 상태 변경 확인 카드 준비 (저장 안 함) |
| 신청 초안 생성 | 화면만 | 화면의 '근무 환경 준비' 메뉴를 안내 |

## 출력 형식

- 항목별 상태(미진행 / 진행 중 / 완료 / 해당 없음)와 해당 없음 사유
- 초안만 있고 완료가 아니면 "초안 작성됨, 실제 신청 전"으로 구분해 말한다.
- 투입 시작일을 함께 밝힌다.

## 예외 처리

- 초안이 있다고 신청이 끝났다고 말하지 않는다. 완료는 `applied_at`이 있는 항목뿐이다.
- 상태 변경을 요청받으면 `prepare_checklist_update`로 확인 카드를 준비한다. 저장했다고 말하지 않는다.
- 도구가 `ok: false`이면 오류 내용을 전달한다.

## 성공 기준

- 항목 상태가 도구 결과와 일치하고, 초안 작성과 실제 신청 완료를 혼동하지 않는다.
- 평가 질문 `evals/questions.json`의 Q8 정답 도구 순서를 따른다.
