# 매출귀속 프로젝트별 검수 금액

## 사용 시점

- "B 업체의 9월 검수 금액을 매출귀속 프로젝트별로 알려줘."
- "C-2026-103 계약 총액 얼마야?"

## 맡는 질문

- 업체·계약번호의 월 검수 금액(원), 매출귀속 프로젝트별 금액, 계약 총액(계약 기간 전체)
- 인력의 매출귀속 프로젝트·MM이 무엇인지만 묻는 질문은 인력관리 카테고리가 맡는다.

## 필수 입력

| 입력 | 없을 때 |
| --- | --- |
| 업체명 또는 계약번호 | 물어본다 |
| 계약번호 | 비워서 호출한다. 업체의 계약이 여러 건이면 도구가 계약번호 목록과 질문을 돌려주니 그대로 물어본다 |
| 연도·월 | 비워서 호출한다(이번 달). 답변에 검수 기간을 밝힌다 |

## 실행 절차

1. `inspection_amount_by_revenue_project(company, contract_no, year, month)`를 호출한다.
2. 결과의 금액 문장(`inspection_total`, `contract_total`, 프로젝트별 `amount`·`contract_amount`)을 그대로 옮긴다.
3. `not_calculated`가 있으면 인력과 이유를 알린다. 계산 불가는 0원이 아니다.
4. 마지막에 `rule`을 한 줄로 덧붙인다(기본안 규칙, 부가세 별도).

## 연결 도구

| 도구 | 상태 | 용도 |
| --- | --- | --- |
| `inspection_amount_by_revenue_project` | 구현 | 업체·계약번호의 월 검수 금액과 계약 총액, 매출귀속 프로젝트별 |
| `search_contracts` | 구현 | 업체의 계약번호 찾기 |

## 예외 처리

- 금액·MM을 직접 계산·반올림하지 않는다. 도구 결과에 없는 금액을 말하지 않는다.
- 과제 리더는 단가 권한이 없어 검수 금액을 볼 수 없다. 도구 오류 문장을 그대로 안내한다.
- 이 서비스의 검수 금액과 구매시스템의 실제 검수·승인은 다르다.

## 성공 기준

- 금액을 지어내지 않고 도구 결과로 답한다.
- 평가 질문 `evals/questions.json` Q7, `evals/eval_set.json` I01·I02의 정답 도구를 따른다.
