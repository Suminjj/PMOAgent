# 매출귀속 프로젝트별 검수 금액

## 사용 시점

- "B 업체의 9월 검수 금액을 매출귀속 프로젝트별로 알려줘."
- 업체·월 단위 검수 MM·금액을 묻는 요청

## 필수 입력

| 입력 | 없을 때 |
| --- | --- |
| 업체명 | 물어본다 |
| 연도·월 | 연도가 없으면 기준일의 연도로 보고 답변에 밝힌다. 월이 없으면 물어본다 |

## 실행 절차

1. `inspection_amount_by_revenue_project(company, year, month)`를 호출한다.
2. 도구는 **구현 예정**이다. 배분·반올림·부가세 규칙이 정해지지 않아 금액을 계산할 수 없다고 안내한다.

## 연결 도구

| 도구 | 상태 | 용도 |
| --- | --- | --- |
| `inspection_amount_by_revenue_project` | 구현 예정 | 업체·월 검수 금액의 매출귀속 프로젝트별 집계 (규칙 TODO) |

## 예외 처리

- 금액·MM을 직접 계산하거나 추정하지 않는다. 0원으로 답하지 않는다.
- 이 서비스의 검수 내역과 구매시스템의 실제 검수·승인은 다르다.

## 성공 기준

- 금액을 지어내지 않고 구현 예정임을 안내한다.
- 평가 질문 `evals/questions.json`의 Q7 정답 도구를 따른다.
